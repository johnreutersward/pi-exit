# pi-exit

> /exit command for [pi](https://pi.dev/)

## About

Every day I would inadvertently send these 5 bytes to a server somewhere:

```
/exit
```

The server would think for a bit and then send back these 8 bytes:

```
Goodbye!
```

Which is incredible. But what I really wanted to do was to exit pi.

## Install

```
pi install git:github.com/johnreutersward/pi-exit
```

## Usage

```
/exit
```
